# Букер — выжимка мастер-блупринта v1.0 (21.08.2026)

Полный текст: локальный файл `Buker_Master_Product_Blueprint_RU.docx`. Этот файл — машиночитаемая выжимка для разработки.

Ограничения пилота: [CONTRACT.md](CONTRACT.md) перекрывает блупринт (цена только с сервера, нет страхования, ИИ не судья, Protect не MVP).

## Неподвижные правила

- Цена / комиссия / возврат только сервером (`quote_id`, `offer_version_id`).
- Три типа рабочих пространств: заказчик, исполнитель, площадка. Код исполнителя в API: `artist` (синоним `performer`). Organization = workspace.
- Состав события — `EventTeamRequirement`, не вечная строка в `notes`.
- Гарант добровольный, обе стороны. AI не меняет статус/цену/спор.
- Event Studio — пошаговый конструктор, не 3D. Turbo не в первом сценарии.
