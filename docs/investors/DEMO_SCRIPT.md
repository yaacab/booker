# Демо-скрипт инвестору (10–12 мин)

Цель: показать **операционную систему сделки** (concierge-first), не каталог контактов. Источник правды: `docs/product/CONTRACT.md`.

**Не показывать:** OTP на экране, `/deals/demo` как «гарант», публичные demo-пароли, слово «эскроу/страховка», stub как live-оплату.

## Подготовка (1 мин, до звонка)

- Prod или staging с founding-артистами и open-data площадками.
- Режим платежей: `BOOKER_PAYMENT_PROVIDER=external` (или честно сказать «external до U5»).
- Аккаунты: заказчик + исполнитель/площадка + admin (без озвучивания паролей в записи).

## Путь (тайминг)

| Мин | Шаг | Что сказать |
|-----|-----|-------------|
| 0–1 | Лендинг → `/search` | «Букер — Deal OS: дата → цена с сервера → договор → деньги. Пилот Москва, concierge.» |
| 1–3 | Каталог | Founding artists (verified + календарь). Площадки open-data: чип «владелец не подключён» / ориентировочный календарь — честно. |
| 3–5 | Event Studio `/events/new` | Состав события, роли, заявка. Цена не считается на фронте. |
| 5–7 | Deal Room | Оффер / `quote_id`, hold даты, конфликт слотов запрещён. |
| 7–9 | Договор → оплата | Подписание; external: «оплата вне платформы, статус подтверждает Букер». |
| 9–11 | Кабинеты + admin | Supply отвечает; audit / metrics — воронка, не vanity GMV. |
| 11–12 | Ask / гейты | Diligence-ready сейчас; live-эквайринг после OPERATOR + юрист + партнёр (Wave G). |

## Закрытие

North star: оплаченные подтверждённые брони без double-book. KPI года 1 — в CONTRACT, не 10k артистов.
