# Pitch outline — 10 слайдов

Текст истины для deck (PDF/Google собирает владелец). Тон: concierge OS, не «Uber для артистов».

1. **Проблема** — сделка события размазана по мессенджерам; нет hold, quote, статуса оплаты.
2. **Инсайт** — покупают не «ещё один каталог», а сопровождаемую сделку на софте.
3. **Продукт** — Букер Deal OS: каталог → Studio → оффер/`quote_id` → hold → договор → платёж → кабинеты.
4. **Демо** — 90 сек скрина пути из `DEMO_SCRIPT.md`.
5. **Модель запуска** — founding supply, Москва, calendar gate; 80–150 профилей цель года 1.
6. **Unit economics** — take rate 8–12% или фикс+эквайринг; цена только API.
7. **KPI / north star** — оплаченные брони, fill, time-to-offer, double-book = 0; см. `METRICS_SNAPSHOT.md`.
8. **Конкуренты** — доски объявлений и agency CRM; Букер = статус сделки + серверная цена.
9. **Риски и гейты** — draft legal, external pay → U5; честно (`RISKS_AND_GATES.md`).
10. **Ask** — капитал/время под diligence → paid-pilot; не обещать live-эквайринг без юриста и партнёра.
