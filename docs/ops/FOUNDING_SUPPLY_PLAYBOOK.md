# Founding supply — playbook outreach

Цель года 1 (CONTRACT): **80–150** founding-профилей. Продукт даёт кабинет + верификацию + календарь; плотность — операционная работа владельца.

## Active profile (критерии выдачи)

Карточка **в выдаче**, только если:

- цена (тариф) на сервере;
- календарь **≥30 дней** open/доступности;
- медиа / представитель;
- верификация (`verified` / approved).

Без календаря — **не в выдаче**. Open-data площадки с синтетическим календарём помечать честно (`openDataVenue` / «календарь ориентировочный») и переводить на owner calendar через outreach.

## ICP supply пилота

DJ, ведущий, фото, декор, площадка (Москва). Не ICP: туры, билеты, второй город, white-label.

## Критерии отбора founding

1. Реальные выступления / площадка в Москве или МО.
2. Готовность отвечать <2 ч в пилоте.
3. Юрлицо или ИП на старте платежей (НПД — позже).
4. Согласие вести календарь в Букере (не только «визитка»).
5. Одна категория фокуса на профиль; мультиуслуга — через Services, не хаос в имени.

## Outreach (короткий цикл)

1. Shortlist 30–50 контактов по категории.
2. Письмо: Deal OS + take rate/concierge, не «регистрация в каталоге».
3. Онбординг: тариф + 30д слотов + медиа → заявка на верификацию.
4. Первые 1–2 сделки — с сопровождением Букера (external pay ок).
5. Еженедельно: % active profiles, time-to-offer, отказы «вне продукта».
