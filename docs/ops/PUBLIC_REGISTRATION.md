# Публичная регистрация — legal gate

Публичная саморегистрация Букера закрыта по умолчанию. Один серверный флаг применяется
независимо в API и web:

```env
BOOKER_PUBLIC_REGISTRATION_ENABLED=0
```

Отсутствующее, ошибочное или любое отличное от точного `1` значение оставляет web-форму
закрытой. API использует булево значение с production default `false` и отклоняет прямой
`POST /auth/register` с `403`. Вход существующих пользователей, восстановление пароля и
team invitations продолжают работать.

## Когда разрешено включение

Перед `BOOKER_PUBLIC_REGISTRATION_ENABLED=1` должны быть выполнены все условия:

- заполнены реквизиты и статусы оператора в `docs/legal/OPERATOR.md`;
- получено письменное заключение российского юриста по `docs/legal/LAWYER_BRIEF.md`;
- утверждены политика ПДн, согласия и версия legal pack для журнала согласий;
- подтверждены контур хранения ПДн в РФ и статус уведомления РКН;
- владелец отдельно разрешил публичный сбор ПДн и выпуск точного SHA.

После этого выставить `1` одновременно в окружении `booker-api` и `booker-web`, затем
перезапустить оба сервиса. Проверить `/login?mode=register`, успешную тестовую регистрацию,
журнал согласия и обычный вход. Расхождение флагов между API и web считается ошибкой
конфигурации; API остаётся последним обязательным барьером.

Rollback: вернуть `0` или удалить переменную в обоих сервисах и перезапустить их. Уже
созданные аккаунты при этом сохраняют возможность входа.

## Локальная разработка и тесты

Окружение `development` или `test` само по себе регистрацию не открывает. Для ручного
локального сценария значение нужно задать явно и одинаково для API и web:

```env
BOOKER_PUBLIC_REGISTRATION_ENABLED=1
```

API pytest включает регистрацию через явную fixture `public_registration_enabled`.
Playwright-конфигурация явно передаёт `1` существующим onboarding-сценариям. Проверка
закрытого контура запускается отдельно на изолированной SQLite-базе:

```bash
cd apps/web
BOOKER_DATABASE_URL=sqlite:////tmp/booker-registration-gate-e2e.db \
BOOKER_API_URL=http://127.0.0.1:8042 \
BOOKER_WEB_URL=http://127.0.0.1:3042 \
BOOKER_CORS_ORIGINS=http://127.0.0.1:3042 \
BOOKER_PUBLIC_REGISTRATION_ENABLED=0 \
npx playwright test e2e/registration-gate.spec.ts --workers=1
```
