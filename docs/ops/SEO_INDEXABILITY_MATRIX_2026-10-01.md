## Автоматические гарантии

- `GET /catalog/public-index` отдаёт исчерпывающий курсорный список только доступных анонимно профилей.
- Sitemap проходит все страницы публичного индекса, удаляет дубликаты и не подменяет сбой API пустым успешным ответом.
- Серверные страницы профилей превращают API 404 в Next.js 404; API 5xx остаётся ошибкой и виден мониторингу.
- Данные профиля передаются клиентскому компоненту как initial data, поэтому ключевой контент присутствует в первом HTML и не требует отдельной загрузки в браузере.

## Релизная проверка

После публикации проверить снаружи: `robots.txt`, `sitemap.xml`, 200 опубликованных профилей, 404 скрытых/несуществующих профилей, canonical и robots meta, а также HTML-ответ с отключённым JavaScript. Индексация поисковиком и состояние в кабинетах вебмастеров здесь не заявлены.
