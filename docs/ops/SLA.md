# SLA пилота Букер

Пока нет выделенной смены 24/7: экстренную поддержку ведёт живой оператор.

| Ситуация | Цель ответа | Кто |
|----------|-------------|-----|
| Неявка / срыв даты в день события | 30 минут в рабочее окно 10:00–22:00 МСК | Оператор |
| Платёж прошёл, бронь не Confirmed | 2 часа в рабочие дни | Оператор + доступ к `audit_logs` |
| Спор в Deal Room | Первичная квалификация 1 рабочий день | Оператор. ИИ не выносит решение |
| Инцидент ПДн | Уведомление 24 ч, итог 72 ч | Ответственный за ПДн |

Канал пилота: Telegram оператора (не публиковать в оферте до юрпроверки). Эскалация возврата — два отдельных действия администраторов с TOTP: запрос `POST /admin/refunds`, затем подтверждение другим оператором `POST /admin/refunds/{id}/approve`. Pending означает ожидание результата, не выплаченный возврат.
