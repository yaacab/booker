На основных кадрах «рамка слота» двигает только выбранный фрагмент: desktop −14 px, mobile −8 px, пик на 0,72 с, возврат к 1,28 с. Свет меняет opacity 0,75 → 1 → 0,75. Timeline 2 с. Заголовок и CTA не анимируются. Figma MP4 mobile был экспортирован, но воспроизведение кадров не проверено: URL экспорта временный. Источником остаётся файл Figma.

В этих кадрах нет фотографий поставщиков, цен, обещаний доступности или оплаты. Слова «выбор ещё не бронь» и пилотное ограничение денег видимы. Фактическая дата, район, доступность и цена для последующих экранов должны приходить из API.

Прототипные переходы записаны в Figma: desktop «Посмотреть площадки» → desktop Choice; mobile «Каталог» → mobile Choice; Error «Повторить» → Loading; Conflict «Альтернативы» → Choice. Это визуальная навигация, а не исполнение API. Экран первого шага создания события теперь существует; переходы Home → Event Studio и Event Studio → Date/District нужно связать после утверждения его композиции владельцем.

## Следующий дизайн-проход

1. Доработать `дата → район → площадка`: результат с подтверждёнными данными API, обычный список, конечную карусель и её keyboard/scroll-snap состояния; проверить смену рамки после ответа API, а не по клиентскому нажатию.
2. Choice проверен отдельными кадрами на 320/200% и 768 с длинными русскими названиями и клавиатурным порядком. Ещё нужны интерактивная keyboard/scroll-snap проверка, контраст инструментом и непрозрачный fallback кнопок. Главная на 320 проверена только как отдельный статичный кадр.
3. После утверждения первого шага дорисовать шаги `место → команда → бюджет → проверка`, связать путь home → event → search → profile → request → deal и показать кликабельный прототип до переноса визуального языка в frontend.
4. Затем закрывать остальные строки реестра 75 семейств + 18 детальных кадров и применимые состояния из [карты экранов](SCREEN_FLOW_MAP.md).

Текущие Home, Choice и первый шаг Event Studio закрывают только часть трёх семейств реестра. Их нельзя выдавать за завершение 93 дизайн-заданий или за утверждение итогового дизайна.
