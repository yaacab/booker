# Event Studio — интеграция свободной сборки

14.10.2026. BK-DESIGN-FLEX. Интеграционный срез для рабочего web Букера от CORE-кандидата `d741d689bcdda134ab0e415a64a12a65bd09f5ea`. Implementation commit: `4a042916a273e91eebe7c964dbd7d59df0056918`. Production не изменён.

## Что перенесено

- Event Studio Map включена по умолчанию; классический мастер остаётся доступным через `?event_studio_map_v1=0` и переменную окружения для быстрого rollback.
- Семь разделов — дата и время, гости, артист, площадка, райдер, формат и бюджет — доступны из постоянного меню и заполняются в любом порядке.
- Дата открывает календарь, время — прокручиваемые колонки часов и минут с клавиатурным управлением.
- Диалоги, карточки и меню имеют непрозрачный фон; мобильный layout сохраняет доступные области нажатия.
- Бюджет заказчика вводится одной суммой и уходит в API как `budget_rub`; каталог показывает отдельный ориентир, итоговая цена по-прежнему определяется только серверным предложением.
- Профили артиста и площадки передают точный resource ID в Studio. При отправке события Studio создаёт серверные requests к выбранным ресурсам; это заявка, а не подтверждённая бронь.
- В профиле артиста при открытом слоте доступна немедленная заявка через существующий `/quick-request`; без слота заказчик переходит в Studio с уже выбранным артистом.
