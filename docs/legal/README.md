## Что этот пакет сознательно не закрывает

- Выбор и правовую пригодность формы оператора: владелец сообщил о своём НПД, но оператор сделки, допустимый вид дохода и договорная схема ещё не установлены.
- Уведомление Роскомнадзора (подаёт оператор).
- Договорную схему с ЮKassa: у владельца есть аккаунт, но подключение решения для нескольких поставщиков, выплаты, возвраты и фискализация для Букер не подтверждены.
- Силу оферты до подписи/утверждения юристом.
- Protect / страхование.
