# Шаблон тарифа отмен (приложение к офферу)

**Статус:** не норма права и не условие Букер по умолчанию. Вставляется в конкретную `OfferVersion`, если стороны и юрист согласны. Не ограничивает императивные права потребителя.

Утверждённых процентов в этом файле нет. Пока условия отмены не согласованы и не включены в принятую версию договора, оператор не применяет примерную сетку удержаний.

## Матрица параметров для обсуждения с юристом

Ориентир от даты начала слота, если стороны не согласовали иное:

| Когда заказчик отменяет | Что происходит с оплаченным через партнёра |
|-------------------------|--------------------------------------------|
| До hold / до акцепта оффера | Платёжа ещё нет — отмена без расчёта |
| После оплаты до оказания услуги | Для B2C — возврат за вычетом документально подтверждённых фактических расходов, связанных именно с договором; фиксированный процент не применяется автоматически. Для B2B — формула только после проверки юристом и фиксации в активной версии |
| Частичное исполнение | Отдельно определить стоимость фактически оказанной части и подтверждённые расходы; расчёт делает API по утверждённым правилам, оператор не вводит сумму вручную без основания |
| Неявка / отмена близко к событию | Не означает автоматическое удержание 100%; нужны квалификация B2B/B2C, договорное основание и доказательства расходов/убытков |

Отмена по вине исполнителя: слот освобождается; возврат заказчику — по офферу; повторная дата — новая бронь.

Штраф «100% всегда» без привязки к убыткам юрист должен вычеркнуть, если заказчик — потребитель.

Комиссия Букер при отмене: только как в активной версии оффера и утверждённой модели услуг оператора. Невозвратность комиссии нельзя объявлять абсолютной для потребителя. Любой расчёт — только API; этот файл не является тарифом.
