# Тексты согласий в интерфейсе

**Статус:** черновик редакции `2026-08-18`. Короткие формулировки для галочек. Длинные документы — по ссылкам.

Версия пакета, которая уходит в аудит при регистрации: `2026-08-18-draft`.

## Обязательно при регистрации

1. «Принимаю [оферту цифровых услуг](/legal/offer). Понимаю: Букер не исполнитель выступления, цена только с сервера, текст пока черновик до утверждения юристом.»

2. «Соглашаюсь на обработку персональных данных по [политике](/legal/privacy) для аккаунта и сделки.»

Без обеих отметок регистрация не создаётся.

## Отдельно, по умолчанию выкл.

3. «Согласен получать рекламные сообщения на email (38-ФЗ). Можно не отмечать: сервисные письма по заявке всё равно нужны для сделки.»

## Вход

Повторный акцепт оферты при каждом входе не требуется, пока юрист не скажет иначе. Ссылка на документы — в подвале сайта.

## Восстановление пароля

Запрос email не раскрывает, есть ли аккаунт. Письмо на пилоте не отправляется.

## Deal Room / договор сторон

OTP-подпись — акцепт черновика прямого договора сторон, не акцепт оферты Букер заново.
