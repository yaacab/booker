# Фаза 0: платёжный партнёр (РФ)

Букер **не** эскроу-банк. Слой `PaymentProvider` + webhooks + идемпотентность + ежедневная сверка.

## Шортлист (не выбор, а кандидаты для юриста и финансов)

| Партнёр | Зачем смотреть | Ограничения |
|---------|----------------|-------------|
| ЮKassa | Привычный эквайринг, webhooks, фискализация через партнёров | Не полноценный эскроу; схема агента/сервиса с юристом |
| Тинькофф / Т-Банк эквайринг | Юрлица и ИП, API | Самозанятые — отдельный контур |
| Точка Банк | Агентские схемы для площадок | Проверить лимиты и оферту |
| CloudPayments | Интернет-эквайринг | Юрисдикция и 54-ФЗ |
| НКО / расчётный партнёр под безопасную сделку | Ближе к hold средств | Долгая интеграция; гейт U5 в прод |

Боевой провайдер за фичефлагом `BOOKER_PAYMENT_PROVIDER`. Сейчас в коде: `stub`.

## Пилот

- Получатели: юрлица и ИП. Самозанятые (НПД) — фаза Market fit.
- Повтор webhook с тем же `event_id` возвращает сохранённый ответ.
- Неуспешный платёж не переводит бронь в `Confirmed`.

## Гейт в прод

Юрист + выбранный партнёр + сверка + чеки 54-ФЗ. До этого Alpha может идти со счётом вручную с пометкой «вне защиты платформы».
