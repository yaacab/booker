# AGENTS.md — Букер

- Бренд: **Букер**. Репозиторий: `booker`. Не смешивать с THE AIV.
- Источник правды по продукту: `docs/product/CONTRACT.md`.
- Цена, комиссия, возврат — только API.
- Платёжный прод — после юриста и партнёра (`docs/legal/`).
- Публичные домены: канон **bukergo.ru**; `bookergo.ru` и `bukergo.online` — редирект. DNS: `docs/ops/DOMAINS.md`.
- Когда законченная часть работы проверена и ей нужен коммит, самостоятельно фиксировать только её файлы отдельным коммитом, без повторного вопроса владельцу. Если для проверки GitHub нужен push в текущую рабочую ветку, отправить проверенный коммит и продолжать следующую независимую работу, пока CI идёт; результат CI проверить позже. Не включать в коммит соседние незавершённые изменения, секреты и временные файлы. Деплой согласовывать отдельно.
- Каждое сообщение в чате по проекту начинать с актуального процента общей готовности Букера в формате с двумя знаками после запятой (например, «Готовность проекта: 52,00%.»). Источник текущей оценки и фиксированных весов — `docs/PROJECT_PROGRESS.md`; прежняя оценка 84% заменена пересчётом полного запуска от 02.10.2026. После завершения критерия из реестра сразу пересчитывать процент и показывать изменение в процентных пунктах и остаток. Не начислять баллы за один лишь тест, работу в процессе, незавершённый gate или повторно за уже учтённый результат. Формат сотых не означает точность прогноза.
